# Pruebas de Software - Aplicación móvil de red social

## Descripción del proyecto

Este repositorio fue creado para realizar pruebas de software sobre una aplicación móvil de red social.

La aplicación permite:

- Crear un perfil personal.
- Seguir a otros usuarios.
- Publicar texto, imágenes y videos.
- Dar likes y realizar comentarios.
- Enviar mensajes privados.
- Buscar usuarios.
- Consultar contenido mediante un feed.

## Problemas encontrados

Durante las pruebas se identificaron los siguientes errores:

1. Notificaciones duplicadas.
2. Problemas al cargar imágenes y videos.
3. Fallos al cargar archivos de gran tamaño.
4. Lentitud en el feed.
5. Bloqueos al desplazarse rápidamente.
6. Resultados incorrectos en la búsqueda de usuarios.

## Pruebas propuestas

Para comprobar y mejorar el funcionamiento de la aplicación se realizarán:

### Prueba ágil
Pruebas de regresión automatizadas para verificar que los errores corregidos no vuelvan a aparecer.

### Prueba en la nube
Pruebas ejecutadas en diferentes entornos para comprobar el funcionamiento y rendimiento de la aplicación.

### Prueba de seguridad
Análisis del código para encontrar posibles errores o vulnerabilidades que puedan afectar la información de los usuarios.

## Objetivo

Comprobar que la aplicación sea estable, segura y que sus principales funcionalidades trabajen correctamente antes de su lanzamiento.
